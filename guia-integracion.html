Guía de Integración

Character Forge
Cómo integrarlo en tu web

Todo lo que tu equipo técnico necesita para implementar el sistema de análisis de avatares 3D con generación de historias por IA.

Cómo funciona el sistema
1. UploadUsuario sube GLB/GLTF o imagen
2. RenderThree.js renderiza el modelo 3D
3. CapturaScreenshot automático del avatar
4. IA VisionClaude analiza los rasgos
5. HistoriaClaude genera narrativa consistente
1
Obtener la API Key de Anthropic

El sistema usa la IA de Anthropic (Claude) para analizar los avatares y generar historias. Necesitas una API key activa.

🔗 Cómo obtenerla

1. Ve a console.anthropic.com
2. Crea una cuenta o inicia sesión
3. Ve a API Keys → Create Key
4. Copia la clave (empieza con sk-ant-...)
5. Guárdala en un lugar seguro — no se puede ver de nuevo

⚠️
NUNCA expongas la API key en código frontend público. Debe ir en el backend (servidor) de tu web, no directamente en el HTML que me ve el usuario.
2
Crear el endpoint en tu servidor (Backend)

Tu web necesita un endpoint propio que reciba las peticiones del frontend y las reenvíe a la API de Anthropic con la key guardada de forma segura.

Opción A — Node.js / Express
// archivo: server.js  (instalar: npm install express cors)
const express = require('express');
const cors = require('cors');
const app = express();

app.use(cors());
app.use(express.json({ limit: '20mb' }));

// Guarda la API key en variable de entorno (.env)
const API_KEY = process.env.ANTHROPIC_API_KEY;

app.post('/api/claude', async (req, res) => {
  const response = await fetch('https://api.anthropic.com/v1/messages', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'x-api-key': API_KEY,
      'anthropic-version': '2023-06-01'
    },
    body: JSON.stringify(req.body)
  });
  const data = await response.json();
  res.json(data);
});

app.listen(3000);
Opción B — PHP (si tu hosting usa PHP)
<?php  // archivo: claude-proxy.php
$apiKey = 'sk-ant-TU_KEY_AQUI'; // o usar getenv()
$body   = file_get_contents('php://input');

$ch = curl_init('https://api.anthropic.com/v1/messages');
curl_setopt_array($ch, [
  CURLOPT_POST           => true,
  CURLOPT_POSTFIELDS     => $body,
  CURLOPT_RETURNTRANSFER => true,
  CURLOPT_HTTPHEADER     => [
    'Content-Type: application/json',
    'x-api-key: ' . $apiKey,
    'anthropic-version: 2023-06-01'
  ]
]);

header('Content-Type: application/json');
echo curl_exec($ch);
curl_close($ch);
?>
Opción C — Python / FastAPI
# pip install fastapi uvicorn httpx python-dotenv
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
import httpx, os

app = FastAPI()
app.add_middleware(CORSMiddleware, allow_origins=["*"], allow_methods=["*"], allow_headers=["*"])

API_KEY = os.getenv("ANTHROPIC_API_KEY")

@app.post("/api/claude")
async def proxy(body: dict):
  async with httpx.AsyncClient() as client:
    r = await client.post(
      "https://api.anthropic.com/v1/messages",
      headers={"x-api-key": API_KEY, "anthropic-version": "2023-06-01"},
      json=body, timeout=60
    )
    return r.json()
3
Modificar la URL en el HTML del Character Forge

En el archivo character-forge.html hay dos llamadas fetch(). Cambia la URL directa de Anthropic por tu endpoint propio.

Busca esto en el HTML (2 veces)
// ❌ URL DIRECTA — no usar en producción
fetch('https://api.anthropic.com/v1/messages', { ... })
Reemplázalo por tu endpoint
// ✅ URL DE TU SERVIDOR
fetch('/api/claude', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ /* mismos parámetros */ })
})
ℹ️
Nota: El cuerpo del request (model, max_tokens, messages) no cambia. Solo cambia la URL y desaparecen los headers de autenticación del frontend.
4
Agregar las librerías externas (CDN)

El HTML carga estas dependencias automáticamente desde CDN. Si tu web usa Content Security Policy (CSP), debes permitirlas:

Librería Para qué sirve CDN
Three.js r128 Renderizar modelos 3D (GLB/GLTF) cdnjs.cloudflare.com Requerida
GLTFLoader Cargar archivos GLB/GLTF cdn.jsdelivr.net Requerida
OrbitControls Rotar el modelo con el mouse cdn.jsdelivr.net Opcional
Google Fonts Tipografía (Cinzel, EB Garamond) fonts.googleapis.com Opcional
Estos scripts ya están incluidos en el <head> del HTML
<script src="https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js"></script>
<!-- GLTFLoader y OrbitControls se cargan dinámicamente al subir un modelo 3D -->
5
Configuración del servidor (CORS y límites)

Los avatares 3D pueden pesar varios MB. Configura estos parámetros en tu servidor para evitar errores:

📦 Tamaño máximo del request

Los modelos GLB y capturas en base64 pueden superar 5MB. Configura el límite a 20MB mínimo en tu servidor.

⏱️ Timeout del request

La IA puede tardar hasta 30 segundos en responder. Configura el timeout del servidor a 60 segundos mínimo.

🌐 CORS

Permite requests desde el dominio de tu web hacia el endpoint /api/claude.

🔒 Variables de entorno

Guarda la API key en un archivo .env o en las variables de entorno de tu hosting. Nunca en el código.

6
Agregar el HTML a tu página

Tienes dos formas de insertar el Character Forge en tu web:

Opción A — Página independiente (recomendada)
<!-- Sube character-forge.html a tu servidor y enlázalo -->
<a href="/character-forge.html">Abrir Character Forge</a>
Opción B — Embebido via iframe
<iframe
  src="/character-forge.html"
  width="100%"
  height="900px"
  style="border:none;border-radius:16px"
></iframe>
Checklist final antes de publicar
  • Cuenta en console.anthropic.com creada y con créditos activos
  • API Key generada y guardada en variable de entorno del servidor
  • Endpoint /api/claude creado en el backend (Node / PHP / Python)
  • Las 2 URLs de fetch() en el HTML apuntan al endpoint del servidor
  • Límite de body del servidor configurado a 20MB
  • Timeout del servidor configurado a 60 segundos
  • CORS habilitado en el endpoint
  • CDN de Three.js y jsDelivr no bloqueados por CSP
  • Probado con un archivo GLB y con una imagen PNG
